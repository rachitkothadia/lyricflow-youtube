LyricFlow

Lyrics work without a key using LRCLIB. Romanization runs locally.

Clicking the extension toolbar icon sends 10 seconds of the active YouTube tab audio to AudD. No microphone or listening history is collected. Capture stops before upload; clips are not saved locally. The public test key has a small shared daily quota. Add your own AudD token for continued recognition.

Leave blank to use the public test key. Tokens stay in this Chrome profile and are sent only to AudD.
